# coolest-art-01

A chrome rhinoceros beetle carrying a tiny glowing city on its back, on a
pure black void — one bold shape, extreme contrast, built to stop a glance
and still read at 300 pixels wide. Entry for make.fun's coolest-art-01.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

`main.ts` copies `entry.png` to `/output/entry.png` byte for byte, so both
grading runs write the same file.
